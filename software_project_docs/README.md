# NuBlox controlled project documents

This directory contains the **live controlled project documents** for the NuBlox Enterprise Operating System programme.

The document templates are maintained separately under [`../software_project_docs_templates/`](../software_project_docs_templates/). Templates are not working documents and should not be edited to record NuBlox programme decisions.

## Document control

All controlled documents should follow the metadata requirements defined in:

[`../software_project_docs_templates/00_Templates/Document_Control_Metadata_Template.md`](../software_project_docs_templates/00_Templates/Document_Control_Metadata_Template.md)

Each working document records:

- a stable NuBlox document ID;
- document type and template used;
- version and lifecycle status;
- owner, reviewer and approver;
- classification and retention fields;
- related/superseded documents;
- storage location and access permissions;
- change history and Git audit trail.

## Current programme position

The initial product and investment hypotheses are now documented but **not approved**.

The strongest current product hypothesis is that NuBlox can create value by reducing the operational divide between:

```text
operating the organisation
+
delivering the work through which it creates value
```

The current launch-market hypothesis is UK mid-market multidisciplinary built-environment consultancies and project-services firms. This remains subject to direct customer validation.

## Approval discipline

A Draft document records current programme thinking; it is not an approved baseline.

Documents should progress through review and approval only when their material assumptions are supported by sufficient evidence for the decision being made.
