## Milestone rules

1. A milestone is evidence-based, not activity-based.
2. A milestone is not complete because a date has arrived.
3. Each milestone must have a named accountable owner before baseline approval.
4. Completion evidence must be stored or referenced in controlled project artifacts.
5. Missed milestones require forecast and impact updates; they are not silently moved.
